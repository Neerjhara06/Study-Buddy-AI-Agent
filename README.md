# Study Buddy AI Agent

## Overview

An AI-powered study assistant built using Python, Streamlit, and LangChain.

## Features

- Upload PDF, TXT, CSV, PPT
- AI Summarization
- Topic Extraction
- Quiz Generation
- Flashcards
- Progress Tracking

## Tech Stack

- Python
- Streamlit
- LangChain
- Pandas

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
