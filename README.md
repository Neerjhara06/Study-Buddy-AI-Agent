# 📚 Study Buddy AI Agent

An AI-powered study assistant built with **Python, Streamlit, and LangChain** that helps students learn smarter by summarizing notes, extracting key topics, generating quizzes, creating flashcards, and tracking study progress.

## Features

* Upload PDF, TXT, CSV, and PPT/PPTX files
* AI-powered text summarization
* Important topic extraction
* Automatic quiz generation
* Flashcard creation
* Concept explanation
* Study planner
* Progress tracking dashboard

## Tech Stack

* Python
* Streamlit
* LangChain
* Pandas
* Matplotlib
* Google Generative AI
* Jupyter Notebook

```bash

cd Study-Buddy-AI-Agent
pip install -r requirements.txt
streamlit run app.py
```
